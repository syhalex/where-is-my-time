# WhereIsMyTime

使用原生 HTML、CSS 和 JavaScript 的时间记录网页，无需安装前端依赖或后端。支持本机运行和 GitHub Pages，数据保存在当前浏览器中。

在线地址：https://syhalex.github.io/where-is-my-time/

运行 `npm start` 后打开 `http://127.0.0.1:4173/`，或使用项目提供的桌面启动方式。两个入口使用同一本机地址。旧 `localhost` 地址的浏览器数据可从旧地址导出 JSON，再在 `127.0.0.1` 导入。运行 `npm test` 检查时间、统计、事件、分类、备份和颜色逻辑。

## 记录与查看

- 年、月、周、日视图支持点击、用鼠标或手指拖动，以及用方向键切换。默认打开日视图。手机端默认收起时间总览，查询、事件与分类、对比和备份与分享仍可使用。
- 每天以四条六小时时间带展示，可跨时间带拖拽，精确到五分钟。时间输入框可直接输入或使用上下按钮调整。
- 一条记录只对应一个事件，时长始终根据起止时间计算。名称中的加号按普通字符保存。
- 相同名称自动归为同一事件，共享颜色和分类。在“事件与分类”中可以按名称搜索、重命名、改色、设置分类或删除，修改直接保存。记录弹窗也可快捷选择事件、分类或新建分类。
- 不再被记录使用的事件及没有事件的分类自动清理。记录弹窗中新建的分类随记录一起保存；在管理中创建分类时可多选所属事件，至少选择一个。分类的事件数量可点击查看所属事件。
- “从上条结束继续”与时间边界吸附帮助连续记录。当天记录按事件合并时长，展开后可编辑各段记录；支持删除及撤销删除。快捷事件按最近选择排序，顺序保存在当前浏览器中。
- 月历随机展示每天的两个事件名称。年度热力图以所选分类在显示年份内的单日最高时长为最深色，图例等分显示时长。

## 统计与颜色

- “关注分类”显示自选分类在当前周期中的总时长与占比，选择保存在浏览器中。年视图的统计卡片和热力图使用同一个年度分类。
- 只为有手动记录的过往日期补齐“其他时间”，归入未分类。它参与统计与一天的时间分布，不进入当天记录列表、编辑时间带或事件管理。
- 今天、未来日期和没有记录的日期不会补齐。补齐内容按需计算，不写入备份；补录后会自动重算。
- 随机颜色会避开已有颜色和最近使用的候选颜色，并尽量拉开视觉差异。支持换一组候选色、可视化颜色面板和十六进制输入。
- 右上角“查询”支持精确到分钟的任意时间段，复用记录页的日历和时间输入组件，可在事件或分类中多选，查看合计时长、占比及各事件／分类明细。选择另一组时自动清空原组；跨越查询边界的记录只计区间内部分。占比分母为区间内全部手动记录时长，不含自动补齐的“其他时间”。
- 导出图片可选择模块、下载 PNG 或复制图片。日平均时长可选择分类以及当前年或当前月，按所选分类的总时长除以该期间的记录天数计算。导出中的日视图保持圆环在左，全天分布及图例完整显示，不附加“当前年视图”“时间总览”标题。复制图片需要浏览器支持剪贴板图片写入。

## 备份

“事件与分类”右侧的“对比记录”支持 2–6 份记录，每份分别选择自己的记录或导入的 JSON 备份，再独立选择日期及填写展示名称（留空为记录1、记录2等）。点击末尾虚线“＋”添加卡片，可移除任意卡片，至少保留两份。桌面端卡片等宽缩窄至可读宽度后横向滚动，手机端纵向排列。导入比较的备份只留在当前页面内存中，不合并、覆盖或写入自己的记录。

至少两份来源与日期齐全后自动生成对照图，新卡片填好来源和日期后加入，期间保留已有对比图；切换来源、日期或修改展示名称时自动更新。只要有卡片尚未配齐来源和日期，或正在读取备份，全屏、复制图片、PNG 和 SVG 按钮均置灰，配齐或移除未完成卡片后恢复。对照图按凌晨、上午、下午、晚间显示四组时间条，每组按卡片顺序排列所有已配置记录，共用相同比例，同名事件统一颜色。窄色块的完整文字通过与全屏时间带一致的折线向外展开，中间排预留独立说明区，画布随记录数量和内容增加高度。可全屏查看、复制图片、导出包含全部记录的高清 PNG 或保留文字和矢量图形的 SVG；导出不包含操作控件。

右上角“备份与分享”提供 JSON 导出、导入和查询本机备份。预览窗口列出实际有记录的日期，可以逐日查看事件、分类和起止时间。文件有问题时，窗口会显示原因，以及还能读取的记录。当前格式为版本 4，包含 `categories`、`events` 和 `entries`。

“合并找回”保留现有记录并补回缺失时段，遇到不同记录重叠时暂停并指出冲突时段。“替换回滚”以备份内容替换所有当前记录。两种方式都可以逐日查看操作前后的差异，确认后才写入。写入前会保存当前原件，便于之后再次回滚。

## 版本更新与恢复

- 数据使用固定键 `where-is-my-time.data`，内部的 `version` 独立记录格式版本。网页版本号与数据版本号分别管理。
- 旧键只用于首次导入。启用固定键后，以其中的数据为准，不会因为旧键记录更多而恢复已经删除的记录。
- 升级前以原始字符串保存副本，读回确认备份成功，再迁移和验证记录数量、每条记录的日期与起止时间、事件及分类引用。通过后原子写入固定键，保留旧键。
- 自动副本按原始内容去重，最多保留五份不同内容。系统优先保留当次操作前的原件，再按创建时间保留其余副本。旧版存储键仍可单独查询。
- 备份失败、迁移失败、数据损坏或格式高于当前程序支持版本时，不覆盖原数据，锁定写入并显示恢复入口。可在“备份与分享 → 查询本机备份”查看副本或导出原件。
- JSON 导入兼容旧版本。旧多事件记录转换为一个包含原名称的合并事件，原文件继续保留。当前编辑器仍是一段时间对应一个事件。
- 网页更新保留同一来源、同一浏览器配置中的数据；本地地址与 GitHub Pages 来源不同。首次迁移需在本地导出 JSON，再在在线页面导入。网页不会自动将时间记录上传到 GitHub。
- 浏览器内副本仍属于网站存储，清除网站数据会同时清除副本，请保留 JSON 文件备份。

## GitHub Pages

仓库 Settings → Pages，选择 Deploy from a branch，分支 `main`，目录 `/(root)`。相对资源路径兼容 `/where-is-my-time/` 子路径，无需构建。

发布只包含源码与静态资源。`recovery/`、`output/`、浏览器导出、运行日志和编译后的启动器均不纳入版本控制。

## 分享当天记录

“备份与分享 → 复制分享链接”只分享下方“记录一天”所选日期的手动记录，包含事件名称和起止时间，不包含分类、颜色设置或其他日期。链接携带压缩快照，无需后端；分享后的修改不会同步到旧链接。获得完整链接的人可以查看内容。

打开分享链接自动弹出使用全屏时间带样式的只读窗口，点击“和我对比”可生成分享记录与自己记录的对照图；自己的日期可以独立选择，并可使用现有的全屏、复制图片、PNG 和 SVG 导出。分享快照仅在内存和当前标签页的 sessionStorage 中使用，不导入、不合并、不覆盖本机记录；以分享链接启动时也不会自动迁移或清理写入本机数据。

分享使用浏览器的 Compression Streams API 和剪贴板写入功能，建议使用现代浏览器并通过 HTTPS 或本机 `127.0.0.1` 地址打开。空日期无法生成链接，过长的链接会提示改用图片或备份文件。

完整分享链接读取成功后，快照暂存在当前标签页，地址栏替换为简短的 `#shared=…` 地址，刷新仍可查看。该地址仅对当前标签页有效；转发需使用最初收到的完整分享链接。临时存储不可用时保留原链接，避免刷新后丢失。

“对比”的数据来源支持“分享链接”：粘贴完整链接后自动读取分享日期并生成对比图。读取仅解析链接内的数据，不请求链接地址，也不会写入自己的记录。对比图不显示顶部日期标题；各行仍保留各自的展示名称和日期。

图片导出使用本地打包的 html2canvas 1.4.1（MIT），打开导出时按需加载，直接绘制 Canvas，不使用 SVG foreignObject 承载 HTML。预览、复制和下载共用已生成的 PNG；iOS 限制画布像素并在生成后检查空白图片。运行时不会从 CDN 加载渲染器，也不会上传记录。
